# AI Prompt

## Project Title

**IoT-Based Smart Water Meter Monitoring System for Sri Lanka**

---

## Project Description

Develop a modern, professional, responsive mobile application using **React Native (JavaScript)** with **Firebase** backend.

The system consists of two separate mobile applications.

1. User Mobile App
2. Government Authority Mobile App

The system receives real-time data from an ESP32-based Smart Water Meter.

ESP32 is connected with

* Flow Sensor
* Pressure Sensor 1
* Pressure Sensor 2
* Solenoid Valve
* Battery Management System (BMS)
* Hydro Generator Charging System

The ESP32 uploads all sensor values to Firebase Realtime Database.

Both mobile applications retrieve and update data in real-time.

The application must follow modern Material Design 3 with premium UI/UX.

Primary colors:

Blue

White

Light Gray

Dark Navy

Use smooth animations and beautiful dashboards.
